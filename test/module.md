# Назначение

Проверять экспорт ресурсов MCP в файловые скиллы, сохранность пользовательских
изменений и явные отказы при неполном каталоге или несовместимом контракте.

# Границы

Тесты работают с временными каталогами и изолированным MCP-сервером-фикстурой.
Они не меняют глобальные скиллы и конфигурацию Codex.
